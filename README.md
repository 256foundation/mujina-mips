# Mujina Improvement Proposals (MIPs)

A MIP is a design document for a substantial change to Mujina: a
written, reviewable artifact for an area too big to settle in a
discussion thread. In the spirit of Bitcoin's [BIPs][bips] and
Nostr's [NIPs][nips].

## When to write one

Most ideas start as a [GitHub Discussion][discussions] and stay there,
where the thread is the record. A few grow into something that needs a
document people will edit and refer back to. Those become MIPs.

## How it works

1. Start in [Discussions][discussions]. Every MIP begins as a
   discussion, so ideas are seen as they emerge and nobody has to
   watch this repo.
2. When it needs a document, open a pull request here adding
   `mip-NNNN-title.md`, and link it from the discussion. The PR is
   where the document itself is read and revised.

Process beyond that is intentionally light for now; we will firm it up
as we learn what works.
